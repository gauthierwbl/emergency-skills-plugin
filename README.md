# Emergency Skills Plugin

Projet universitaire de création d’un plugin de skills pour assistant IA agentique.

## Objectif

Fournir des skills capables d’aider à la décision en situation d’urgence :
- météo,
- géolocalisation,
- risques,
- équipements sensibles,
- données territoriales.

## Technologies

- Python
- Codex CLI
- Claude Skills Architecture
- APIs publiques

## Skills actuels

### meteo_urgence

Récupère :
- température,
- vent,
- coordonnées GPS,
- météo actuelle d’une ville.

API utilisée :
- OpenMeteo
