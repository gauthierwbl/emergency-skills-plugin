# Troubleshooting

## Erreur 504 Overpass API

Cette erreur peut apparaître lorsque l’API Overpass met trop de temps à répondre, notamment sur des zones denses comme Paris.

Solutions possibles :

- réduire le rayon de recherche ;
- relancer la commande ;
- tester une autre zone ;
- conserver les autres résultats de l’analyse même si ce module échoue.

## Adresse introuvable

Vérifier que l’adresse est suffisamment précise.

## API indisponible

Certaines APIs publiques peuvent être temporairement indisponibles.
